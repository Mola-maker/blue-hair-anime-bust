# 资产说明

## 成品模型

- `models/蓝发动漫少女·服装配色精修.blend`：主工程，含高精度主体、面部与发丝细节、服装肩带、18 根骨骼、动画，以及隐藏的轻量独立骨骼版本。
- `models/蓝发动漫少女·服装配色精修轻量版.blend`：便于直接打开和修改的轻量工程。
- `models/蓝发动漫少女·服装配色精修版.glb`：高精度交换与网页下载版本。
- `models/蓝发动漫少女·服装配色精修轻量版.glb`：轻量交互与网页默认加载版本。

## 参考图

- `references/原始胸像参考.jpg`：角色、发型、面部与胸像范围参考。
- `references/服装配色参考.jpeg`：仅用于冷白蓝服装、深蓝肩带和配色；未把全身、耳机、吉他加入模型。

## 网页副本

`web/model.glb`、`web/model-hires.glb` 和 `web/reference.jpg` 是为静态查看器准备的运行副本，内容与 `models/`、`references/` 中对应资产一致。

## 完整性

`asset-manifest.json` 记录模型、参考图、预览图和网页二进制资产的字节数及 SHA-256。文本源码不列入该资产清单，可通过 Git 历史或 ZIP 文件清单核对。

远程 GitHub 文本仓库不包含上述二进制资产；完整资产随 ZIP 交付。
